# README resource artwork

The Hugging Face mark is the unmodified full-color logo served by Hugging Face:
https://huggingface.co/front/assets/huggingface_logo-noborder.svg

Official brand assets and guidance: https://huggingface.co/brand

`hugging-face-logo.svg` preserves the downloaded source. `checkpoint.svg` embeds
its original paths and colors, with only uniform scaling and positioning.
Hugging Face's logo remains the property of Hugging Face.

The paper, book, and checklist illustrations were created for the GSPR README.
All four cards are self-contained SVGs with explicit colors, no external fonts,
scripts, remote images, or dependency on a badge service.
